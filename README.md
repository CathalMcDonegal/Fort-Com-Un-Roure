# Fort Com Un Roure

Aplicació web progressiva (PWA) en català per fer activitat física suau a casa.

## Funcions inicials
- Biblioteca d'exercicis per categories i nivells.
- Instruccions senzilles, temps orientatiu i consells de seguretat.
- Temporitzador amb pausa i reinici.
- Comptador de sessions desat al dispositiu.
- PWA amb memòria cau per consultar-la sense connexió després de la primera càrrega.

## Publicació
Activa GitHub Pages a Settings → Pages → Deploy from a branch → main → /(root).

## Seguretat
Contingut general i educatiu; no és un programa de rehabilitació ni substitueix una valoració professional. Cal adaptar l'activitat a cada persona i aturar-se davant dolor, mareig, dolor al pit o falta d'aire inusual.
